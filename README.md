# Commander Buddy

Tools for commanders in Guild Wars 2, as a [Raidcore Nexus](https://raidcore.gg/Nexus) addon.

## What's inside

- Squad overview per subgroup with boon coverage and warnings.
- Roles and markers per player, shown on your own squad list or over the game's squad list.
- A window with your pinned key players (tanks, healers, kiters).
- A log of who left, joined or switched character or spec, with an alert when someone with a role leaves.
- A radial menu for squad markers, a compact marker bar, and a pull timer.
- Roles and notes per raid or strike boss, ready to copy into chat.

The addon is available in Dutch, English and German.

## Requirements

- [ArcDPS](https://www.deltaconnected.com/arcdps/) and [DPS Buddy](https://github.com/NINTEH-cloud/DpsBuddy) for the squad data.
- Squad markers need a key bound in the game (Options > Control Options).

## Installation

1. Install [Raidcore Nexus](https://raidcore.gg/Nexus).
2. Download `CommanderBuddy.dll` from the [latest release](https://github.com/NINTEH-cloud/CommanderBuddy/releases/latest).
3. Put it in `Guild Wars 2/addons/` and load it in the Nexus addon library.

Updates arrive automatically through Nexus.

## Reporting a bug or idea

Open an [issue](https://github.com/NINTEH-cloud/CommanderBuddy/issues), or use the **Report a bug** button in the addon's settings. A screenshot and your addon version (shown in the settings) help a lot.

## Fair play

The addon does not read or change game memory and does not automate gameplay. Every key it sends is a single press that you trigger yourself, never a macro.
